## Professional Philosophy

I believe strong organizations are built by combining clear outcomes, capable people, dependable systems, and useful information.

My operating principles are:

1. Build systems that enable people to succeed without constant supervision.
2. Use data to improve decisions, not merely to produce reports.
3. Standardize what must be consistent while preserving room for initiative.
4. Automate repetitive work so people can focus on higher-value problems.
5. Design technology around business outcomes rather than technical novelty.
